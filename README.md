# oshiro-img-2

Castle girl card art bucket 2 for the Oshiro Database site (oshiro.altterisk.cc), served via jsDelivr:
`https://cdn.jsdelivr.net/gh/Altterisk/oshiro-img-2@main/art/<CardID>_<n>.webp`

Generated by tools/make_art_buckets.py from the game's Card<CardID>.aar textures
(tools/export_card_art.py) - do not edit files by hand. Card IDs 9056-9291 (and every new card).
Game art (c) DMM GAMES / the Shiro Project:RE developers.
